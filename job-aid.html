Find the Correct Course ID (CID)

Use before every alignment or gap-filling project

1Answer three questions first

  • Which school year?Current or upcoming. CIDs can change from one year to the next.
  • What content source?Company-built, vendor, legacy, or new curriculum.
  • Base or linked course?The base course, a linked school copy, or a state-specific base course.

2Pick the right tool

Course Manager

Finding one course or a few. Fastest for a single lookup.

Course Metadata Report

Comparing many courses or locations at once in a spreadsheet.

3Course Manager settings

FieldSet toWhy
Search TextAll or part of the course nameWorks like any search bar
CurriculumAnyNarrowing can hide the course you need
Subject AreaAnyCourses may be tagged unexpectedly
School YearYear from step 1CIDs change between years
Include LinkedCheckedShows school copies with their base
Managed AtOrganization rootAnything else searches the wrong catalog
Available AtAny location, or the schoolCourses are tagged to schools, not states

4Course Metadata Report settings

FieldSet toWhy
School Year(s)Every year you needCompare years side by side
Output TypeExcelInline adds data you don't need
Managed AtOrganization rootThe report won't run otherwise
Available AtAny location, or specific schoolsSpecific schools make a smaller file

Then select Generate Report, turn on filters, and narrow by location, school year, subject, and grade.

5Tell base from linked

Check the Base Course ID column. Blank means a base course. A CID means a linked copy of that base course.

CIDNameBase Course IDResult
789Essential Math 6 A(blank)blankBase course
345Connected Math 6 A789Linked to 789

6Check before you start work

  • School year matches the project
  • Course name and school or state match
  • Base or linked matches what the project needs
Common mistakes
  • Taking the first search result without checking it
  • Narrowing Curriculum or Subject Area
  • Leaving Managed At on anything but the organization root
  • Searching by state when courses are tagged to schools

Still not sure? Ask before you edit. A wrong CID can change a live course students are using.
